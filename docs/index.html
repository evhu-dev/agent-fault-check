Built for Real CI Merge Gates

No flaky LLM-as-a-judge heuristics. Deterministic network faults paired with hard state assertions.

1. HTTP Fault Injection Proxy

Intercepts agent HTTP tool calls and injects commit_then_fail (response dropped after upstream write), fail_before_upstream, and malformed_json.

2. State & Budget Assertions

Verifies actual side effects in PostgreSQL, Redis, and HTTP state endpoints alongside max_tool_calls and no_duplicate_writes retry checks.

3. Native CI & Security Reports

Outputs console summaries, JUnit XML, and SARIF 2.1.0 (AFC101–AFC201) with automatic secret redaction for GitHub Code Scanning.
